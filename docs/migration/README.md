## Часть 1. Старый аккаунт (mikhailkozlov@allstate.com)

### Шаг 1.1. Письмо в поддержку: отвязать телефон (обязательно, 10 минут)

Зачем: новый аккаунт проверяется по SMS. Ваш номер сейчас привязан к старому
аккаунту, и второй раз его не примут, пока поддержка его не отвяжет.

Что уже сделано: 25 октября вы написали в поддержку из старого аккаунта.
Поддержка ответила, что запрос нужно прислать **с новой личной почты**, а рабочую
почту `mikhailkozlov@allstate.com` поставить **в копию (CC)**. В письме нужно
подтвердить, что вы хотите отвязать номер.

1. Откройте рабочую почту Allstate и найдите письмо от поддержки Anthropic
   («Hi Mikhail, I understand you need to unlink your phone number…»).
2. Посмотрите адрес отправителя этого письма (строка «From» / «От»). Запишите
   его: на этот адрес нужно писать.
3. Откройте личную почту **Levsha2002@hotmail.com** (outlook.com).
4. Нажмите **New mail** / **Создать**.
5. В поле **To / Кому** вставьте адрес отправителя из пункта 2.
6. Нажмите **Cc / Копия** и вставьте: `mikhailkozlov@allstate.com`
7. В поле **Subject / Тема** вставьте:

   ```
   Unlink phone number from Claude account mikhailkozlov@allstate.com
   ```

8. В текст письма вставьте:

   ```
   Hello,

   This is Mikhail Kozlov. As your support team asked, I am writing from my new
   personal email address (Levsha2002@hotmail.com) with my work email
   (mikhailkozlov@allstate.com) in CC.

   I confirm that I want my phone number unlinked from the Claude account
   registered to mikhailkozlov@allstate.com, so that I can use the same number
   to verify my new personal Claude account (Levsha2002@hotmail.com).

   My data has already been exported. Once the number is unlinked, I will cancel
   the subscription on the old account and then delete it.

   Thank you,
   Mikhail Kozlov
   ```

9. Нажмите **Send / Отправить**.
10. Ответ придёт на Levsha2002@hotmail.com (копия — на рабочую почту), обычно
    в течение 1–3 рабочих дней.
11. ☐ Поддержка подтвердила, что номер отвязан. Только после этого переходите
    к Части 2.

Если в письме поддержки нет адреса отправителя или ответ не приходит 3 рабочих
дня: откройте в браузере **support.claude.com**, нажмите значок сообщения внизу
справа, укажите почту Levsha2002@hotmail.com и вставьте тот же текст.

## Часть 2. Новый аккаунт

1. claude.ai → внизу слева своё имя → **Log out**.

### Шаг 2.2. Зарегистрироваться

1. Откройте **claude.ai**. Нажмите **Sign up** или введите email.
2. Email: **Levsha2002@hotmail.com**.
   Почему этот: на нём уже ваш GitHub (`levsha2002`) и Google Drive агентства.
   Один адрес на всё — меньше путаницы.
   Не используйте `@allstate.com`.
3. Откройте почту Levsha2002@hotmail.com, найдите письмо от Anthropic и нажмите
   ссылку для входа.
4. Введите имя: Mike Kozlov.

### Шаг 2.3. Оформить подписку

1. Внизу слева своё имя → **Settings** → **Billing** (или **Upgrade**).
2. Выберите тот же план, что был в старом аккаунте (Pro или Max).

На несколько дней у вас будут две подписки одновременно. Это нормально: старую
вы отмените в Части 5.

### Шаг 2.4. Заполнить профиль

1. Settings → **Profile** (или **General**).
2. Найдите поле «What should Claude know about you» / «Personal preferences».
3. Вставьте текст из файла `docs/migration/prompts/02-profile-and-memory.md`,
   раздел **Profile**. Короткая версия, если файл открыть сложно:

   ```
   I am Mikhail (Mike) Kozlov, owner of M&K Agency Inc, an Allstate Exclusive
   Agent in Florida City, FL (agency R3001). I serve clients in English, Spanish
   and Russian; reply to me in Russian. On business topics act as a professional
   analyst from Goldman Sachs, PwC or Deloitte: recommendation first, quantified,
   no filler. I read on mobile. Compliance first: never write prices, discounts,
   carrier comparisons or other carrier names, the word "independent" for my
   agency, availability beyond Mon–Fri 9am–6pm ET, coverage guarantees, or AI or
   prerecorded voice calls. My website repository is levsha2002/mkagencyinc-site.
   ```

4. Нажмите **Save**.

### Шаг 2.5. Подключить Google Drive, Calendar, Slack и GitHub

1. Settings → **Connectors**.
2. Найдите **Google Drive** → **Connect**. Войдите в Google как
   **Levsha2002@hotmail.com**. Разрешите доступ.
3. То же для **Google Calendar**.
4. То же для **Slack**, **Netlify**, **Apollo.io**, если ими пользуетесь.
5. **Microsoft 365 не подключайте**: это система Allstate.
6. GitHub: откройте **claude.ai/code**. Нажмите **Connect GitHub**. Войдите как
   **levsha2002**. Когда GitHub спросит, к каким репозиториям дать доступ,
   выберите **mkagencyinc-site** (и **mkagencyinc**, если нужен).

### Шаг 2.6. Перенести память

1. Settings → **Memory** (в некоторых версиях **Settings → Capabilities**).
2. Убедитесь, что память включена.
3. Нажмите **Start import** (или **Import memory**).
4. Откройте в Drive документ
   [memory-import-ready](https://docs.google.com/document/d/1n_gwGhAfJ3rWJMLYgivuVIZBFUVvIX6mI0BAl23kyzs/edit).
5. Скопируйте всё, начиная со строки **«===== IMPORT FROM HERE =====»** и до конца.
6. Вставьте в окно импорта → **Add to memory**.
7. Через минуту откройте Settings → Memory и проверьте, что записи появились.

Перед импортом прочитайте блок **OPEN QUESTIONS** в конце документа. Там 4
вопроса, на которые нужен ваш ответ (например, Carolina и Nova). Если знаете
ответ — исправьте текст до вставки.

## Часть 4. Новый компьютер

Для работы с сайтом ничего устанавливать не нужно: Claude Code работает в облаке
через браузер. Нужно только приложение Claude и браузер.

### Шаг 4.1. Установить Claude Desktop

1. На новом компьютере откройте браузер → **claude.ai/download**.
2. Скачайте версию для Windows, установите.
3. Откройте приложение, войдите в **новый** аккаунт.

### Шаг 4.2. Разрешить встроенному браузеру Google Ads (нужно для проверки рекламы)

На старом компьютере в приложении Claude был список сайтов, которые встроенный
браузер может открывать. Без него Claude не сможет проверять Google Ads.

1. На **старом** компьютере нажмите клавиши **Win + R**, вставьте
   `%APPDATA%\Claude` и нажмите **Enter**.
2. Скопируйте файл `claude_desktop_config.json` на флешку или в Drive.
3. На **новом** компьютере после установки приложения: **Win + R** →
   `%APPDATA%\Claude` → **Enter** → положите туда этот файл (с заменой).
4. Закройте и снова откройте Claude Desktop.

Если что-то не получится, напишите Claude в новом аккаунте: «Помоги добавить
ads.google.com, business.google.com и www.google.com в список разрешённых сайтов
встроенного браузера».

### Шаг 4.3. Ключи сайта (желательно, можно позже)

Ключи сайта (база Neon, почта Resend, xAI для чата) хранятся в Vercel, сайт
работает без вашего участия. Рекомендую заменить их на новые один раз, потому что
они упоминались в старых чатах. Когда будете готовы, напишите Claude в новом
аккаунте: «Помоги заменить ключи Neon, Resend и xAI для сайта mkagencyinc.com по
шагу 4.3 плана переезда». Он проведёт по шагам.

### Шаг 4.4. Файлы со старого компьютера

Данные можно хранить на старом компьютере. Если хотите перенести:
папку `Desktop\mk-agency-next` (со скрытым файлом `.env.local`) и папку `media`
скопируйте на флешку. Для работы сайта это не обязательно: всё нужное есть в
GitHub и Vercel.

## Часть 5. Закрыть старый аккаунт (только после Части 3)

### Шаг 5.1. Отменить подписку

Поддержка напомнила: сначала отменить подписку, потом удалять аккаунт.

1. Войдите в **старый** аккаунт на claude.ai.
2. Своё имя → **Settings** → **Billing** → **Cancel subscription**.

### Шаг 5.2. Удалить аккаунт

1. Settings → **Account** → **Delete account**. Подтвердите.
2. Это необратимо: все старые чаты пропадут. Всё нужное уже в Drive.
3. Если вместо кнопки написано «Contact support» — напишите в поддержку через
   **Get help**: «Please delete this account».

### Шаг 5.3. Выйти из старого аккаунта везде

- В приложении Claude на телефоне: Settings → Log out, затем войти в новый.
- В Claude Desktop на старом компьютере: то же самое.
